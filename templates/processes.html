A new process adds its load to the simulated server: a CPU-bound one competes for a core, a memory-hungry one grows the working set, an I/O-bound one adds disk requests. Kill it and the load disappears.

Process states now

RUNNING = on a vCPU · READY = runnable, waiting in the run queue · WAITING = sleeping until disk I/O / a page-in completes · BLOCKED = waiting for a lock · SLEEPING = idle · TERMINATED = exited (exit code shown) · RESTARTING = being re-created by the supervisor.

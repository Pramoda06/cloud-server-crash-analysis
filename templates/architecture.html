One sample (every 0.5 s)

  1. A running experiment program applies its scheduled control changes.
  2. Effective inputs follow the controls with inertia (τ 1 s rising, 2.5 s falling).
  3. State variables carry over between samples: CPU run queue, disk backlog, request (accept) backlog, and the previous error rate and in-flight requests (the cascade feedback).
  4. Every node is computed in dependency order; each records its contributions (which input added how much).
  5. The detector evaluates its rules on the observed values only; a level is confirmed after 2 samples.
  6. Attribution decides, from the contributions at the moment each rule first fired, whether a failure was caused by another one (secondary) or is a root (primary).
  7. Episodes, timeline events, the sample for the charts and the recording are written.

Real vs simulated

REAL Read-only psutil readings of this computer (shown as host telemetry, and used only if Anchor baseline to this computer is on).

HYBRID CPU and memory when the anchor is on: real baseline + simulated load.

SIMULATED The process table, locks, injected path delay/loss — and every control.

DERIVED Everything else: computed by the formula shown in Simulation details when you click a value.

Nothing on the host is stressed — no CPU burn, memory allocation, disk writes, network shaping, signals or real locks — so the application can never freeze, and a run with the anchor off is exactly reproducible from its seed.

Cascade links (can be switched off)

  • Memory → disk: major page faults read pages from swap: swap I/O = page faults × 0.25 IOPS joins the disk demand.
  • Memory → CPU: paging overhead (kernel reclaim / fault handling) is CPU time.
  • Slow service → memory: in-flight requests (Little's law, L = λ·W) each hold 1 MB.
  • Failures → load: clients retry 80% of failed requests (retry storm).
  • Disk → memory stalls: page-fault stalls get longer when the swap device is slow.

When a feedback loop keeps the server failed after the trigger is removed, the engine reports a self-sustaining (metastable) failure and how to break the loop.
